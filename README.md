# 🧸 拼豆小店 · 夏日星光拼豆节

一个运行在 iPhone 上的拼豆小店管理应用 —— 线下预约、活动展示、作品记录，一站式搞定！

## ✨ 功能一览

| 功能 | 说明 |
|------|------|
| 🏠 **首页** | 暑期「夏日星光拼豆节」活动展示，今日预约概览，作品墙 |
| 📅 **预约** | 选择日期 + 时段 + 人数，每人每天每时段限 35 人，满员自动拦截 |
| 👤 **我的** | 预约历史统计、手机拍照上传拼豆作品、编辑个人信息 |

## 📱 如何在 iPhone 上使用

### 方式一：同一 Wi-Fi 下访问（推荐，最简单）

1. 在电脑上打开终端（Terminal），进入本文件夹
2. 运行：`python3 -m http.server 8080`
3. 查看电脑 IP 地址：按住 Option 点击菜单栏 Wi-Fi 图标，或运行 `ifconfig en0 | grep inet`
4. 在 iPhone Safari 浏览器中输入：`http://你的电脑IP:8080`
5. 点击 Safari 底部 **分享按钮** → **「添加到主屏幕」**
6. 命名「拼豆小店」→ 完成！之后就像普通 App 一样使用

### 方式二：部署到 GitHub Pages（长期使用）

1. 将整个文件夹上传到 GitHub 仓库
2. 在仓库 Settings → Pages 中启用（source: main branch）
3. 在 iPhone Safari 访问 `https://你的用户名.github.io/仓库名`
4. 同样「添加到主屏幕」

## 🔧 技术说明

- **无需网络**：首次加载后可离线使用
- **数据存储**：所有数据存在手机本地（Safari localStorage），换手机会丢失
- **无后端**：纯前端应用，无需服务器、数据库、账号注册
